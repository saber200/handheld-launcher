# FantasyHub 改造实现规格书

> **这份文档给编码 AI / 开发团队直接执行。** 目标：把现有 `handheld-launcher`（FantasyHub）改造成本规格描述的界面与交互，**不丢失任何既有核心能力**。
>
> 配套资源：`artboards/`（9 张高保真设计稿）、`reference/design-tokens.json`、`reference/mock-data.json`、`tools/`（3 个自动校验脚本）。
> 设计稿为逻辑画布 **1280×720**（前端浮层为 **440×620**），2× 渲染。所有尺寸以 dp 计。

## 1. 导航结构（本次改造最大的变化）

**从「顶部 4 标签 + 抽屉」改为「左侧竖排侧栏 + 抽屉」。**

侧栏固定 8 项，顺序不可变：

| 顺序 | key | 图标 | 标签 | 徽标 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 1 | `home` | home | 首页 | — | 可交互 |
| 2 | `games` | grid | 游戏库 | 库总数 | 可交互 |
| 3 | `apps` | app | 软件库 | 已装数 | 可交互 |
| 4 | `downloads` | download | 下载 | 进行中数 | 可交互 |
| 5 | `files` | folder | 文件 | — | 可交互 |
| 6 | `toolbox` | tool | 工具箱 | — | 可交互 |
| 7 | `store` | cart | 商店 | — | **锁定** |
| 8 | `community` | chat | 社区 | — | **锁定** |

### 1.1 锁定态规则（商店 / 社区）

本版不实现这两个页面。**入口保留以表达产品路线，但必须是明确的禁用态**：

- 图标与文字一律 `ink-4`（#748298），**不得使用 accent**
- 右侧显示 12dp 线性锁图标（`lock`）
- **不可聚焦**：不能进入 `[data-focusable]` 集合
- **LB/RB 分区循环必须跳过**（`TABS` / 导航数组里加 `locked: true`，切换时 filter 掉）
- 读屏播报「商店，即将开放，不可用」
- **不做**「敬请期待」弹窗——禁用入口不得产生任何可交互反馈


## 2. 圆角与间距规范（硬规则，有脚本校验）

### 2.1 圆角阶梯——禁止胶囊与椭圆

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `tag` | **6** | 计数徽标、来源角标、开关轨道、状态点底托、操作 chip |
| `sm` | **8** | 小控件、面包屑、列表行 |
| `chip` | **10** | 分组 chip、侧栏选中行、筛选按钮 |
| `btn` | **12** | 所有按钮 |
| `card` | **14** | 游戏卡、软件卡 |
| `panel` | **16** | 面板、工具箱卡片、信息条 |
| `shell` | **18** | 外层容器（与项目 `--radius: 18px` 一致） |

**只有两类允许是正圆**：状态圆点（运行中 / 平台点，直径 ≤ 9dp）、手柄按键角标（A/B/X/Y，直径 26dp）。

> ⚠️ **必须改的既有代码**：`global.css` 里 `.tab-list` 与 `.tab` 现在是 `border-radius: 999px`（胶囊）。改造后顶部标签条被侧栏取代，若保留任何胶囊形状一律改为上表的矩形圆角。**禁止出现 `border-radius: 999px` 或 `h/2` 形式的全圆角。**

### 2.2 间距规范

| 令牌 | 值 | 含义 |
| --- | --- | --- |
| `cardPad` | **16** | 卡片内边距（四边一致） |
| `panelPad` | **20** | 大面板内边距 |
| `gutter` | **16** | 卡片之间的间距 |
| `stack` | **8** | 同组元素之间的垂直间距 |
| `stackLg` | **12** | 不同组之间的垂直间距 |
| `rowPadX` | **12** | 列表行左右内边距 |
| `safe` | **24** | 页面左右安全边距 |

**硬规则**：
1. 卡片 / 面板里的元素**距边缘 ≥ 16dp**
2. 同组元素（名称↔元信息）间距 **8dp**；不同组（元信息↔按钮）间距 **≥ 16dp**
3. 文字距任何容器边缘 **≥ 3dp**
4. 列表行内容不得贴到行边缘

### 2.3 禁止出现的写法

```css
/* ❌ 禁止 */
border-radius: 999px;
border-radius: 50%;          /* 除状态圆点外 */
padding: 13px;               /* 手感数字，必须走令牌 */
```

### 3.2 交互（必须实现）

| 行为 | 规格 |
| --- | --- |
| 方向键 ←/→ | 在卡片条内移动焦点；**卡片条整体重新居中**（聚焦项居中于内容区） |
| **聚焦项放大** | 1.36×（116×146 → 158×190），`transition: transform 180ms cubic-bezier(.22,1,.36,1)` |
| **hero 换图** | 聚焦项变化时，顶部大图**交叉淡入**换成该游戏的宽图（`opacity` 过渡 160ms）；无宽图时回退到封面图，再回退到程序化占位 |
| 卡片内信息 | **只有名称**（单行，过长缩字号或截断），与你现有 `.library-name` 的极简取向一致 |
| 聚焦卡内信息 | 名称（最多 2 行）+ 一行「时长 · 体积」 |
| 信息面板 | 跟着聚焦项实时切换：名称、类型·开发商·年份、四格数据（总时长/最近游玩/占用空间/兼容性） |
| LT / RT | 切换分组 chip（保留你现有 `useGamepadNav` 的 zone 机制） |
| LB / RB | 切换一级分区（跳过锁定项） |
| A | 启动游戏（未安装时为「安装」） |
| X | 收藏 |
| Y | 卡片菜单：隐藏 / 改名 / 安装 Mod 与工具（**保留现有能力**） |
| 长按 A | 游戏快速菜单（启动项 / 兼容层 / 性能档） |

### 3.3 卡片条几何（居中算法）

```ts
// 未聚焦卡宽 TW=116，聚焦卡宽 FW=TW*1.36=157.8，间隙 G=16，聚焦间隙 FG=20
// 聚焦项必须居中于内容区：contentX=260, contentW=996
function shelfLayout(items, focusIndex, contentX, contentW) {
  const TW = 116, FW = 157.8, G = 16, FG = 20;
  const focusLeft = contentX + contentW / 2 - FW / 2;
  // 向左累加，得到每张卡的 x
  const xs = new Array(items.length);
  xs[focusIndex] = focusLeft;
  for (let i = focusIndex - 1; i >= 0; i--) {
    const wPrev = (i + 1 === focusIndex) ? FW : TW;
    xs[i] = xs[i + 1] - ((i === focusIndex - 1) ? FG : G) - (i === focusIndex - 1 ? TW : TW);
  }
  for (let i = focusIndex + 1; i < items.length; i++) {
    xs[i] = xs[i - 1] + ((i - 1 === focusIndex) ? FW : TW) + ((i - 1 === focusIndex) ? FG : G);
  }
  return xs;
}
```
> **实现注意**：卡片条容器用 `overflow-x: auto` 时，**左右各留 24dp padding**，否则首尾卡的焦点环会被容器裁掉。

### 4.2 两种来源的差异

| | 已装软件（`source: 'local'`） | 预置软件（`source: 'preset'`） |
| --- | --- | --- |
| 包头行 | `● 运行中`（success）或 `● 已安装`（ink-4） | `[官方]` / `[推荐]` / `[基础]` 角标（圆角 6，28dp 内边距） |

| 左下操作 | `A 启动 · X 更新 · Y 打开目录` | `A 安装` |
| 卸载 | 允许（用户自装） | `tag === '基础'` 时**禁止卸载**，提示「系统组件，不可卸载」 |

### 4.3 交互

- LB / RB 切来源（全部 / 已安装 / 预置可安装 / 模拟器 / 工具 / 系统组件）
- 预置「基础」组件在**首次启动引导**中默认勾选
- 安装与更新生成标准下载任务，在下载页（K6）可见、可暂停、可调优先级，进度双向同步
- `Y` 打开安装目录（`installPath`；未安装则禁用）

## 11. 分辨率与缩放

沿用现有做法，**按物理高度换算**：

```ts
export const LOGICAL_H = 720;                 // 本项目逻辑高度（16:9）
export function uiScale(physicalHeight: number, physicalWidth: number) {
  return Math.min(physicalHeight / 1080, physicalWidth / 1280);
}
// 应用到根元素：document.documentElement.style.setProperty('--dp', `${uiScale(h,w)}px`)
```

| 物理分辨率 | 比例 | UI 缩放 | 侧栏 / 顶栏 / 提示条（物理 px） |
| --- | --- | --- | --- |
| 1920×1080 | 16:9 | 1.00× | 236 / 44 / 48 |
| 1920×1200 | 16:10 | 1.00×（按宽度封顶） | 236 / 44 / 48 + 上下留边 |
| 1280×800 | 16:10 | 0.90× | 212 / 40 / 43 |
| 2560×1440 | 16:9 | 1.33× | 315 / 59 / 64 |

> 16:10 屏（1200p）比 16:9 高，**按宽度封顶后纵向会有余量**——用 `justify-content: center` 让内容居中，上下留 `bg-0` 底色，**不要拉伸布局**。
